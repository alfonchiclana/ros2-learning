## Turtlesim + CLI tools

Comandos aprendidos:
- ros2 node list / info
- ros2 topic list / echo / pub / hz
- ros2 interface show
- ros2 service list / call
- rqt_graph

Conceptos:
- Cada terminal mantiene vivo su nodo; al cerrarla, el nodo muere
- cmd_vel (Twist) controla velocidad; pose publica posición
- rqt_graph muestra el sistema en vivo, no un historial
